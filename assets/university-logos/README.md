# University identification logos

Copied on 22 October 2026 from the local Ops PhD Placements assets/logos snapshot (431 files). These are independent copies; the map makes no requests to stouras.com. Filename Q identifiers are retained to preserve identity.

Original source metadata: official institution websites, Wikidata P154/P seal/coat-of-arms files, Wikimedia Commons/Wikipedia, and reviewed overrides. Logos are used for institution identification; their respective owners retain rights. Copying a file does not grant a new licence. See source-metadata.json and logo-review.json for the original provenance snapshot.

Missing or failed logos display initials. New matches must be checked by institution identity, never fuzzy name similarity.

The October 22 expansion covers every current directory institution name. Additional marks were sourced from institutional websites and Wikimedia pages; per-institution sources and retrieval dates are recorded in data/university-logos.json. Institution aliases and named schools may use their parent university mark. Every asset is hosted locally. The map also displays these marks in its accessible results list and popovers. The offline selftest checks that each directory name has a local file; browser verification checks image decoding and rendered coverage.
